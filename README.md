# Avel Ember

Многополосный сатуратор в духе FabFilter Saturn: до 6 полос, 17 стилей сатурации, оверсэмплинг до 8x. Форматы: VST3 (macOS и Windows), AU (macOS).

## Возможности
- **До 6 полос** с фазово-когерентными кроссоверами Linkwitz–Riley 24 дБ/окт. Если сатурация не включена, сумма полос ровная и никак не окрашивает звук.
- **17 стилей:**
  - **Saturation:** Clean, Warm, Gentle;
  - **Tube:** Clean, Warm, Heavy;
  - **Tape:** Tape, Hot Tape;
  - **Transformer;**
  - **Amp:** Clean, Crunch, Heavy;
  - **Clipping:** Soft, Hard;
  - **FX:** Rectify, Foldback, Bitcrush.
- **На каждую полосу:**
  - **Drive** (0–36 дБ);
  - **Dynamics:** плюс выравнивает насыщение, минус сильнее насыщает громкие места;
  - **Tone:** более яркий или тёмный характер искажений;
  - **Feedback:** резонанс вокруг центра полосы;
  - **Mix** и **Level**;
  - обработка **Stereo / Mid / Side / Left / Right**;
  - **Solo, Mute, Bypass**.
- **Auto Gain:** громкость каждой полосы держится на месте, поэтому Drive меняет характер звука, а не уровень.
- **Оверсэмплинг 2x / 4x / 8x** против алиасинга. Общий Mix (параллельная обработка) выровнен по задержке, гребенчатой фильтрации нет.
- **Кривая передачи (Transfer):** живая форма выбранного стиля с точкой текущего уровня сигнала.
- **A/B, Undo/Redo, пресеты:** 13 заводских и свои.

## Управление
| Действие | Как |
|---|---|
| Разделить на полосы | двойной клик по спектру (или правый клик → Split Band Here) |
| Сдвинуть кроссовер | тянуть вертикальный разделитель |
| Убрать кроссовер | двойной клик по разделителю (или правый клик → Remove) |
| Drive полосы | тянуть точку полосы вверх/вниз или колесо мыши над полосой; Shift для точной настройки |
| Bypass полосы | двойной клик по точке |
| Стиль, стерео, solo/mute | панель внизу или правый клик по полосе |
| Отменить / вернуть | Cmd+Z / Shift+Cmd+Z (Ctrl на Windows) |

## Установка
**macOS:** `AvelEmber-<версия>-macOS.pkg`, двойной клик, затем «Установить». Если macOS не даёт открыть файл, зайдите в Системные настройки → Конфиденциальность и безопасность и нажмите «Всё равно открыть».

**Windows:** `AvelEmber-<версия>-Windows-Setup.exe`. Если появится «Windows защитила ваш компьютер», нажмите «Подробнее», затем «Выполнить в любом случае».

## Сборка
- **macOS:** `bash build_mac.sh` собирает плагин и ставит его себе, `bash make_installer_mac.sh` собирает установщик `.pkg` в `dist/`.
- **Windows:** собирается на GitHub (`.github/workflows/build.yml`), установщики публикуются на странице Releases.
